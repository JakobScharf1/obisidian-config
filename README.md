## Setup
Am besten für die Sammlung von Tasks eine oder mehrere Notizen anlegen und dort bei Bedarf neue Tasks anlegen, sodass man diese dort immer gesammelt. Wenn man bspw. über die Timeline Tasks anlegt werden diese in einer neuen Notiz gespeichert. 

## Tasks
Um Tasks zu benutzen, erstellt man Checkboxen per `- [ ] `, diese werden automatisch als Task erkannt. Per `Strg + Shift + P` kann man die Befehlszeile öffnen - wenn man dort *Tasks* eintippt, findet man alle nötigen Shortcuts um bspw. schnell neue Aufgaben zu erstellen.

## Kanban Board
Per `Strg + Shift + P` die Befehlszeile öffnen, *Board* eintippen und *Tasks Kanban: Open board* ausführen.
In diesem Kanban Board werden alle Aufgaben in deinem Vault aufgelistet.
**Todo**: Alle Tasks, die noch nicht abgehakt o.ä. sind
**In Progress**: Alle Tasks, die abgehakt aber nicht durchgestrichen sind (nur über das Board möglich)
**Done**: Alle Tasks, die abgehakt und durchgestrichen sind

## Tagesplanung / Timeline
In der linken Seitennavigation findet man unten die Icons für *Open Timeline* und *Open Multi-Day View*. Ebenfalls natürlich über die Befehlszeile.
In diesen Ansichten findet man alle Tasks, die ein *scheduled date* hinterlegt haben. Standardmäßig funktionieren diese ohne Uhrzeit, werden also als ganztags hinterlegt. Man kann aber einfach hinter das *scheduled date* eine Uhrzeit wie *17:00* schreiben und die Task wird entsprechend in der Ansicht angezeigt.

## Highlighting
Man kann Text inline per Eingabe eines `/Highlightr` farbig markieren.
